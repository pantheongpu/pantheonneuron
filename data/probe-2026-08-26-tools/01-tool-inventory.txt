=== neuron-profile subcommands ===
  capture       Capture a profile given a NEFF        -> produces NTFF v6
  inspect       Wrap a workload, capture system+device -> produces NTFF v115
  show-session  Decode an NTFF
  view          Analyze NEFF+NTFF into reports
                --output-format=[db|summary-text|summary-json|json|perfetto|parquet]

=== TOOL BUG: NTFF version mismatch within one install ===
  neuron-profile inspect  writes NTFF version 115
  neuron-profile show-session reads versions 1-6 only:
    "NTFF version 115 is not supported in this version of the tool
     (supported: 1 - 6). Please upgrade aws-neuronx-tools."
  Use `capture` (v6) rather than `inspect` if you need to decode the result
  with the tooling shipped in the same AMI.

=== ENVIRONMENT TRAPS ===
  1. neuron-profile inspect exec()s its argument as a single path -- it does
     not split on spaces or go through a shell. Pass an executable wrapper
     script, not "python foo.py".
  2. neuron-profile view requires $HOME to be set, or exits:
       "$HOME is not defined"
     SSM RunShellScript runs as root with no HOME.
  3. torch_neuronx deletes its compiler workdir. Pass
     compiler_workdir='/tmp/ccwork' to torch_neuronx.trace to keep the NEFF;
     otherwise there is nothing to hand neuron-profile capture.
